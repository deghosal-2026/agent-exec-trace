# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v0.1.0  | :white_check_mark: |
| < v0.1.0 | :x:              |

Only the latest release is actively supported. Older versions do not receive
security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by emailing
**deghosal@gmail.com**. Do **not** open a public issue.

You can expect:

- An initial response within **48 hours** confirming receipt of your report.
- Regular updates as we investigate and develop a fix.
- Credit in the release notes (unless you request anonymity).

## Scope

This policy covers the entire repository, including:

- The core SDK and instrumentation libraries
- Adapter modules for agent frameworks
- Backend services (collector, processor)
- Web application (dashboard UI)

If you are unsure whether an issue is in scope, report it anyway. We will
triage and let you know.

## Bug Bounties

We do not offer a bug bounty program at this time.
